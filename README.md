# Traditional Rangoli (Android)

Kotlin + Jetpack Compose port of Traditional Rangoli for Android phones and tablets.

iOS app (in review): `Documents/MyApps/TraditionalRangoli`  
This Android app: `Documents/MyAndroidApps/TraditionalRangoli`

**Package:** `com.sreedhar.traditionalrangoli`  
**Publisher:** Sai Laksha Technologies · Sreeo Studio

## Open in Android Studio

1. Open Android Studio.
2. **File → Open** and choose this folder.
3. Trust the Gradle project and wait for sync.
4. Pick a phone or tablet emulator (or a USB device) and press **Run**.
